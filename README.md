📊 Vrinda Store Annual Report 2022 – Excel Dashboard

📌 Project Overview

The Vrinda Store Annual Report 2022 is an interactive Excel dashboard project designed to analyze store sales data and generate meaningful business insights. The dashboard helps understand sales performance, customer demographics, order status, and sales channels through interactive charts and slicers.

🎯 Objectives

- Analyze monthly sales and order trends.
- Compare sales between men and women.
- Understand order delivery and cancellation status.
- Identify top-performing states.
- Analyze sales by age group and gender.
- Compare different sales channels and product categories.

🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Analysis
- Data Visualization

📈 Dashboard Features

- Orders vs Sales: Monthly comparison of sales amount and order count.
- Sales: Men vs Women: Gender-wise sales analysis.
- Order Status: Analysis of delivered, cancelled, refunded, and returned orders.
- Sales by State: Identification of top-performing states.
- Age vs Gender: Customer segmentation by age group and gender.
- Order Channels: Comparison of sales across different online platforms.
- Interactive Filters: Slicers for month, category, and sales channel.

💡 Key Learnings

- Creating interactive dashboards in Excel.
- Using PivotTables and PivotCharts for data analysis.
- Presenting business insights through visualizations.
- Analyzing sales trends and customer purchasing behavior.

🚀 Conclusion

This project demonstrates how Microsoft Excel can be used to transform sales data into an interactive dashboard for business reporting and decision-making.
